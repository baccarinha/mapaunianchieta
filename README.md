
#🗺️ Mapa Interativo UniAnchieta — Navegação Inteligente no Campus

🎯 **Objetivo do Projeto**

Desenvolver um mapa interativo capaz de auxiliar usuários na localização de prédios, salas e setores dentro do campus da UniAnchieta, facilitando a navegação e o acesso às informações.

🧩 **Funcionalidades do Sistema**

|O sistema apresenta as seguintes funcionalidades:|
|--|
🗺️ Visualização do mapa do campus
📍 Identificação de prédios e salas
🔍 Busca por locais específicos
🧭 Navegação entre áreas do mapa
📱 Acesso por dispositivos móveis
🔗 Possibilidade de acesso via QR Code
🏫 Organização de locais por categorias
📌 Marcação de pontos importantes
🖥️ Interface interativa e intuitiva
🛠️ Tecnologias Utilizadas

|Este projeto foi desenvolvido utilizando:|
|--|
HTML5 — Estruturação do mapa
CSS3 — Estilização visual
JavaScript — Interatividade e navegação
GitHub Pages — Hospedagem do projeto
QR Code — Acesso rápido ao sistema
Inteligência Artificial (IA) — Apoio na criação e organização do projeto
